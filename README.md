# 영포티 피하기

[모바일 미리보기](https://emfls.github.io/youngforty-escape-preview/)

민수의 사진과 이름표가 있는 대화창으로 진행하는 모바일 비주얼 노벨입니다. 대화창을 누르면 문장이 완성되고, 다시 누르면 다음 대사를 읽습니다. 최대 8번 답장을 고르며, 앞선 대화에서 얻은 단서로 다음 제안을 바꿀 수 있습니다. 선곡 출처, 공개 예약, 선물 준비와 답장 시간 약속을 활용해 보세요. 엔딩은 종료 요청, 단체 관계 합의, 자랑의 모순을 확인한 결과와 남은 호감도를 함께 반영합니다.

다시 시작하면 세 가지 도입이 차례로 바뀝니다. 상단에서 대화 기록을 확인할 수 있고, 메뉴에서 타이핑 생략, 알림 소리, 차단과 기존 사진 이야기 목록을 열 수 있습니다. 소리는 기본으로 꺼져 있습니다.

## 실행

프로젝트 폴더에서 다음 명령을 실행한 뒤 브라우저에서 <http://127.0.0.1:8791/>를 엽니다.

    python3 -m http.server 8791 --bind 127.0.0.1

정적 HTML·CSS·ES 모듈로 실행합니다. 빌드, 패키지 설치, 로그인, API 키가 필요 없습니다.

## 검증과 구성

    node --test

- chat.mjs는 대사, 점수, 기억할 조건과 다음 상황을 정의합니다.
- chat-rules.mjs는 호감도, 답장 잠금과 엔딩을 결정합니다.
- messenger.mjs는 사진·대화창·선택지·기록과 화면 재생을 관리합니다.
- novel-playback.mjs는 표시 단위 분할과 타이핑·다음 대사 처리를 정의합니다. 게임 규칙은 바꾸지 않습니다.
- episodes.html은 기존 사진 이야기 네 편의 시작 화면입니다.

## 이번 개편의 플레이 검증 (2026-11-07)

Ego Lite에서 답장 버튼으로 11개 경로를 플레이했다. 세 도입과 18개 상황, 아래 다섯 엔딩을 확인했다. `node --test`는 단서별 선택지와 후속 장면, 모든 가능한 경로의 종료 및 마지막 관계 합의를 검증한다.

| 실제 경로 | 턴 / 종료 호감도 | 엔딩 |
| --- | --- | --- |
| 선곡 출처 질문 → 자동추천 확인 → 볼륨 담당으로 정리 | 4 / 51 | 아는 사람은 검색창 |
| 식사 제안을 단체로 전환 → 참석 투표·둘뿐이면 취소 | 5 / 46 | 단톡에서만 봐요 |
| 프로필 준비 질문 → 쿠폰 문구 네 번 선택한 사실 확인 → 취소 | 3 / 47 | 마음은 남고 선은 생겼다 |
| 식사·선물 거절 → 개인 연락 종료 요청 | 6 / 26 | 알림이 평화로워졌습니다 |
| 단체 일정 협의 → 개인 약속은 다음에 다시 이야기 | 6 / 53 | 상대만 썸 타는 중 |

이전 호응이 있어도 마지막 단톡 합의는 성공으로 처리했다(6턴 / 51점). 식당 예약과 카페 선착순 단서는 서로 다른 반응으로 이어졌다. 320×568·390×844 화면, 34px 하단 안전 영역, 데스크톱 460px 폭, 연속 입력·차단·재시작 중 타이머 취소, 키보드·모션 감소·손상된 설정값을 점검했다. 실제 휴대폰 기기 테스트는 하지 않았다.

## 모바일 비주얼 노벨 화면 (2026-11-07)

기존 1280×720 원본 사진을 사용하며 사진마다 초점을 정합니다. 현재 대사와 답장만 표시하고, 앞선 대화는 기록 패널에서 확인합니다. 타이핑 생략 설정도 대사를 자동으로 넘기지는 않습니다. 선택지 표시 중에는 마지막 질문이 고정되고, 짧은 화면에서는 선택지 영역을 스크롤합니다.

기존 대사·단서·게임 규칙·회귀 테스트는 `3464990`과 동일합니다. 새 표시 상태 테스트를 포함한 `node --test`로 검증할 수 있습니다.

Ego Lite의 브라우저 에뮬레이션에서 320×568·390×844·430×932의 시작·대화·선택·기록·엔딩 화면을 확인했습니다. 테스트 18개, 기존 다섯 엔딩의 동일 결과, 한 번 누르면 문장 완성·다시 누르면 진행, 연속 선택 방지, 기록 중 타이핑 정지, 차단·재시작 정리, 안전 영역과 화면 높이 변경을 검증했습니다. 실제 휴대폰 기기에서는 확인하지 않았습니다.

## 메뉴·고정 화면·장면 사진 보완 (2026-11-07)

메뉴는 호감도 표시 아래에서 열립니다. 대화와 선택 단계의 사진·하단 패널 높이는 동일하게 유지하고, 다음 진행은 선택지와 같은 폭·최소 높이의 버튼으로 제공합니다. 짧은 화면에서는 선택지 영역만 스크롤합니다.

취향 이야기·식사 제안·선물 제안·멋쩍은 반응 사진 네 장을 추가해 기존 카페·산책 사진과 함께 상황에 따라 여섯 장을 사용합니다. 장면과 관계 정리 방식에 따라 사진을 선택하며, 대사 한 줄마다 바꾸지는 않습니다. 새 사진은 기존 가상 민수를 기준으로 built-in image_gen으로 생성했습니다. 저장 경로와 실제 프롬프트 세트는 [이미지 생성 기록](images/minsu-scenes-v1.json)에 있습니다.
